# L'Hypnose — Types & Techniques

Le site **L'Hypnose — Types & Techniques** est un site éducatif multi-pages dédié à l'apprentissage sérieux et éthique de l'hypnose.

Contenu — Chaque page est un module complet :

- Les 7 grands courants de l'hypnose avec leurs histoires, mécanismes, avantages et limites
- Les états de transe (naturels et hypnotiques), les ondes cérébrales, les niveaux de profondeur
- Un guide pas à pas d'autohypnose avec verbatims, durées et courbe de progression
- Un protocole d'induction éthique pour guider quelqu'un, avec tests de suggestibilité et lecture des signaux physiques
- Un article complet sur la rupture de pattern — définition, 6 techniques illustrées, éthique
- 9 mythes déconstruits et 11 questions-réponses appuyées sur des études scientifiques publiées
